Building the launcher and installer (MinGW-w64, as used for the released binaries):

  1. The headset bridge (bridge/) and the launcher:
       windres launcher.rc -O coff -o launcher.res
       g++ -std=c++17 -O2 -static -municode -mwindows -Wl,--tsaware ShogoVRLauncher.cpp launcher.res -o ShogoVR.exe -lole32 -luuid -lshell32 -lcomctl32 -ladvapi32 -luser32 -lgdi32 -lwindowscodecs -lmsimg32

  2. The installer's payload - the files it carries:
       python ../tools/makepayload.py payload.bin ShogoVRBridge.exe ShogoVR.exe "Shogo VR Guide.txt" NOTICE.txt

  3. The installer builder (setup.rc embeds payload.bin as resource RCDATA 200):
       windres setup.rc -O coff -o setup.res
       g++ -std=c++17 -O2 -static -municode -mwindows -Wl,--tsaware ShogoVRSetup.cpp setup.res -o ShogoVR-InstallerBuilder.exe -lole32 -luuid -lshell32 -lcomdlg32 -lcomctl32 -ladvapi32 -luser32 -lgdi32 -lwindowscodecs -lmsimg32

The .rc files embed the icon (assets/shogo.ico), the artwork (assets/header.png,
assets/banner.jpg), the Windows manifests and version information.

The installer carries its files as a resource (RCDATA 200, format in
Common.h: PakSerialize), not appended after the program - security scanners
associate appended data with malware droppers. Running the builder with
--build makes a copy of itself and replaces that resource (Windows'
UpdateResource) with the same files plus ShogoVR/CShell.dll and
ShogoVR/AUTHORS.txt (required): that copy is ShogoVR-Setup.exe.

Command lines (also handy for testing):
  ShogoVR-InstallerBuilder.exe --build <CShell.dll> [<output.exe>] [--quiet]
  ShogoVR-Setup.exe [--install <Shogo folder> --quiet]
  ShogoVR.exe [--play | --settings | --uninstall [--quiet]]
